ИНСТРУКЦИЯ: РЕГИСТРАЦИЯ БОТА В MAX И ПОЛУЧЕНИЕ ТОКЕНА
================================================================
Составлено по официальной документации MAX для разработчиков
(https://dev.max.ru) в сентябре 2026.


1. ТРЕБОВАНИЯ ДЛЯ РАБОТЫ С ПЛАТФОРМОЙ
----------------------------------------------------------------
Подключение к платформе MAX для партнёров доступно ТОЛЬКО для:
  - юридических лиц,
  - индивидуальных предпринимателей (ИП),
  - самозанятых,
которые являются резидентами РФ.

Без верифицированного профиля на платформе создать чат-бота нельзя.


2. ПОДКЛЮЧЕНИЕ К ПЛАТФОРМЕ MAX ДЛЯ ПАРТНЁРОВ
----------------------------------------------------------------
Способы входа:
  - веб-версия:  https://business.max.ru/self
  - мини-приложение «MAX для бизнеса» в мессенджере MAX:
    https://max.ru/business_bot?startapp

Шаги:
  1. Откройте веб-версию платформы (или мини-приложение).
  2. Войдите или зарегистрируйтесь (вход по номеру телефона,
     который используется в мессенджере MAX).
  3. Создайте профиль организации, ИП или самозанятого
     и пройдите его верификацию.
  4. После верификации выберите сервисы, к которым подключаетесь
     (вам нужен «Чат-бот»).

Лимиты на количество ботов на один профиль:
  - Организация или ИП:  5 ботов
  - Самозанятый:         2 бота


3. СОЗДАНИЕ ЧАТ-БОТА
----------------------------------------------------------------
  1. Перейдите в раздел «Чат-боты» на платформе.
  2. Нажмите «Создать» (или «+ Создать» для следующего бота).
  3. Заполните карточку бота:
     - Логотип (обязательно):
         формат .jpg / .jpeg / .png,
         размер 500x500 px,
         не более 5 МБ,
         соотношение сторон 1:1.
     - Название чат-бота (обязательно):
         1-59 символов, латиница/кириллица/цифры, без эмодзи.
     - Никнейм (генерируется автоматически, изменить нельзя):
         для ИП и юрлиц:  id + ИНН + "_bot"  (например, id1234567890_bot)
         для самозанятых: se(orgid)_bot
     - Описание (обязательно):
         до 200 символов, что умеет бот.
  4. Нажмите «Создать».

Дополнительно:
  - Ссылка на бота формируется автоматически: max.ru/idИНН_bot
    (так же доступен QR-код).
  - В карточке БЕЗ запрещённых материалов: мат, контент 18+
    и чужие товарные знаки/названия.


4. МОДЕРАЦИЯ БОТА
----------------------------------------------------------------
После создания бот проходит модерацию:
  - Статус «На модерации» — проверка до 48 часов по рабочим дням.
  - Статус «Опубликован»  — бот успешно прошёл проверку.
  - Статус «Нужны исправления» — исправьте данные в карточке
    и отправьте на повторную проверку.

Пока бот «на модерации», изменить настройки нельзя.
Уведомления приходят от бота «MAX для бизнеса» в личные сообщения.
Токен бота появляется только ПОСЛЕ успешной модерации.


5. ПОЛУЧЕНИЕ ТОКЕНА БОТА
----------------------------------------------------------------
  1. Перейдите на платформу (https://business.max.ru/self)
     в раздел «Чат-боты».
  2. Выберите нужного бота.
  3. Нажмите «⋮» (меню) → «Настройки».
  4. Найдите поле «Токен доступа».
  5. Нажмите значок копирования справа от токена.

Пример токена: AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw

ВАЖНО:
  - Токен — это прямой доступ к боту. Не храните его в открытых
    источниках и не передавайте посторонним.
  - Если токен скомпрометирован — обновите его кнопкой обновления
    на той же странице «Настройки».

В нашем проекте токен вставляется в файл config.json:

    {
      "ns_login": "ваш_логин_СГО",
      "ns_password": "ваш_пароль_СГО",
      "ns_school": "МОУ \"Лицей № 4\"",
      "max_bot_token": "ПОЛУЧЕННЫЙ_ТОКЕН"
    }

config.json НЕ хранится в git (добавлен в .gitignore).


6. ДОПОЛНИТЕЛЬНЫЕ НАСТРОЙКИ БОТА
----------------------------------------------------------------
- Приватность («Настройки» → «Чат-бот» → «Приватность»):
    по умолчанию добавление бота в групповые чаты ЗАПРЕЩЕНО.
    Наш бот специально отвечает только в личных чатах, поэтому
    менять этот параметр не нужно.
- Команды бота можно указать в API-методе PATCH /me/commands
  (необязательно для работы нашего бота).
