ИНСТРУКЦИЯ: ЗАПУСК БОТА ОЦЕНОК НА WINDOWS
===============================================================

Состав проекта:
  config.example.json     — шаблон конфигурации
  config.json             — реальная конфигурация (создаётся, в git не хранится)
  grades.py               — загрузка конфига, запрос и форматирование оценок
  main.py                 — CLI: печать оценок в консоль (для проверки)
  bot.py                  — сам бот (Telegram, aiogram)
  requirements.txt        — зависимости
  tests/                  — тесты
  instructions/           — инструкции (REGISTER_TG_BOT.txt и др.)


1. УСТАНОВКА PYTHON
---------------------------------------------------------------
1. Скачайте установщик Python 3.12 с официального сайта:
   https://www.python.org/downloads/
2. Запустите установку.
3. ВАЖНО: в первом окне установщика отметьте галочку
   «Add Python to PATH».
4. Проверьте установку, открыв PowerShell:

   python --version

   Ожидаемый вывод:  Python 3.12.x


2. КОПИРОВАНИЕ ПРОЕКТА
---------------------------------------------------------------
Если проект ещё не у вас — скопируйте папку проекта (или
клонируйте репозиторий). Далее все команды выполняйте
в этой папке проекта.


3. УСТАНОВКА ЗАВИСИМОСТЕЙ
---------------------------------------------------------------
Откройте PowerShell в папке проекта и выполните:

   python -m pip install -r requirements.txt

Либо установите вручную:

   python -m pip install netschoolapi aiogram aiohttp-socks Pillow pytest pytest-asyncio

Проверка (опционально): запуск тестов

   python -m pytest

Ожидаемый вывод:  13 passed


4. СОЗДАНИЕ ФАЙЛА КОНФИГУРАЦИИ config.json
---------------------------------------------------------------
1. Скопируйте шаблон:

   Copy-Item config.example.json config.json

2. Откройте config.json в текстовом редакторе (Блокнот, VS Code) и
   заполните реальными данными:

   - ns_login      — логин учётной записи «Сетевой город»
   - ns_password   — пароль от «Сетевого города»
   - ns_school     — название школы, например "МОУ \"Лицей № 4\""
   - tg_bot_token  — токен бота Telegram (см. инструкцию
                      instructions/REGISTER_TG_BOT.txt)
   - use_proxy     — true/false: ходить к Telegram через прокси
   - proxy_url     — адрес прокси (обязателен, если use_proxy=true),
                     например "socks5://127.0.0.1:10808"
   - output_mode   — "image" — оценки картинкой (PNG),
                     "text" — оценки текстом (запасной вариант).

Например:

   {
     "ns_login": "Ученик123",
     "ns_password": "Пароль123",
     "ns_school": "МОУ \"Лицей № 4\"",
     "tg_bot_token": "1234567890:AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw",
     "use_proxy": false,
     "proxy_url": "socks5://127.0.0.1:10808"
   }

ВАЖНО: файл config.json не попадает в git (он в .gitignore).
Не делитесь им.


5. ПРОВЕРКА ДОСТУПА К ДНЕВНИКУ (ОПЦИОНАЛЬНО)
---------------------------------------------------------------
Проверьте, что логин/пароль/школа в config.json верны:

   python main.py

Бот этого не требует, но удобно узнать, что учётные данные
работают, до запуска бота.


6. ЗАПУСК БОТА
---------------------------------------------------------------
В PowerShell, в папке проекта:

   python bot.py

В окне должны появиться логи. Ищите строку вида:
   INFO ...: Start polling

Бот работает, пока процесс не остановлен.

Чтобы остановить бота: нажмите Ctrl+C в этом окне PowerShell.


7. ПРОВЕРКА РАБОТЫ БОТА В TELEGRAM
---------------------------------------------------------------
1. Откройте Telegram.
2. Найдите бота по его username (например, @my_school_grades_bot)
   или откройте ссылку t.me/my_school_grades_bot.
3. Нажмите «Начать» / отправьте /start.
4. Бот пришлёт приветствие, а над строкой ввода появится
   постоянная кнопка «📊 Получить оценки».
5. Нажмите её — бот пришлёт оценки. Если output_mode="image"
   — придёт картинка-таблица (PNG), если "text" — текст
   с эмодзи-оценками (5️⃣, 4️⃣, ...).
6. Команды:
     /оценки         — оценки за последние 7 дней
     /оценки месяц   — оценки за последние 30 дней

Бот отвечает ТОЛЬКО в личных чатах.


8. ЧАСТЫЕ ПРОБЛЕМЫ
---------------------------------------------------------------
- «python не является внутренней или внешней командой»
    → Python не добавлен в PATH. Переустановите Python,
      отметив «Add Python to PATH».
- «В config.json не задан tg_bot_token»
    → Вставьте реальный токен от @BotFather (см.
      instructions/REGISTER_TG_BOT.txt).
- Соединение с Telegram недоступно, но прокси настроен
    → проверьте use_proxy=true и proxy_url (например,
      "socks5://127.0.0.1:10808"). Прокси-сервер должен быть запущен.
- Ошибка авторизации «Сетевой город» (Ошибка при получении оценок)
    → неверные ns_login / ns_password / ns_school в config.json.
- Кнопка «Получить оценки» не отвечает
    → проверьте, что процесс bot.py запущен и в консоли нет ошибок.
- Не видно кнопки под строкой ввода
    → отправьте /start ещё раз (клавиатура появляется после /start).
- Бот не найден по имени в поиске Telegram
    → проверьте username бота: он передавался в /newbot и
      заканчивается на "bot". Откройте t.me/<username> напрямую.
