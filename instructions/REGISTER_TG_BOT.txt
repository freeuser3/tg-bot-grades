ИНСТРУКЦИЯ: РЕГИСТРАЦИЯ БОТА В TELEGRAM И ПОЛУЧЕНИЕ ТОКЕНА
===============================================================

Никакой верификации бизнеса не нужно — токен выдаётся бесплатно
через официального бота @BotFather.


1. КАК ПОЛУЧИТЬ ТОКЕН (ЧЕРЕЗ @BOTFATHER)
---------------------------------------------------------------
1. Откройте Telegram и найдите официального бота @BotFather
   (https://t.me/BotFather).
2. Нажмите «Start» / отправьте команду /start.
3. Отправьте команду:

     /newbot

4. BotFather спросит название бота (имя, отображаемое в чатах).
   Придумайте любое, например:

     Оценки из Сетевого города

5. Затем спросит username бота — он должен заканчиваться на "bot",
   быть на латинице, без пробелов. Например:

     my_school_grades_bot

6. BotFather ответит сообщением с HTTP API token вида:

     1234567890:AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw

7. Скопируйте токен. Это и есть tg_bot_token.


2. КУДА ВСТАВИТЬ ТОКЕН
---------------------------------------------------------------
Токен вставляется в файл config.json в папке проекта:

    {
      "ns_login": "ваш_логин_СГО",
      "ns_password": "ваш_пароль_СГО",
      "ns_school": "МОУ \"Лицей № 4\"",
      "tg_bot_token": "1234567890:AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw",
      "output_mode": "image"
    }

config.json НЕ хранится в git (добавлен в .gitignore).
output_mode: "image" — оценки картинкой (по умолчанию),
             "text" — оценки текстом (запасной вариант).


3. ЗАПУСК БОТА (кратко)
---------------------------------------------------------------
    python bot.py

В консоли появится:  INFO ...: Start polling
Откройте в Telegram @your_username и отправьте /start.


4. НАСТРОЙКА ПАРАМЕТРОВ (@BotFather) — ОПЦИОНАЛЬНО
---------------------------------------------------------------
- /setcommands — задать список команд для кнопки «/» в Telegram:

     start - Приветствие и кнопка «Получить оценки»
     оценки - Оценки за последние 7 дней
     оценки месяц - Оценки за последние 30 дней

Обратите внимание: Telegram показывает в списке только первую
команду /оценки, но бот всё равно понимает и «/оценки месяц».

- /setdescription — короткое описание бота.
- /setusername — изменить username (если вдруг занят).
- /token — ещё раз показать текущий токен.
- /revoke — отозвать старый токен (например, если он утёк).
