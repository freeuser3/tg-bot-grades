ИНСТРУКЦИЯ: ЗАПУСК БОТА ОЦЕНОК НА DEBIAN
================================================================

Состав проекта:
  config.example.json — шаблон конфигурации
  config.json         — реальная конфигурация (создаётся, в git не хранится)
  grades.py           — загрузка конфига, запрос и форматирование оценок
  main.py             — CLI: печать оценок в консоль (для проверки)
  bot.py              — сам бот MAX
  requirements.txt    — зависимости
  tests/              — тесты


1. УСТАНОВКА PYTHON И ПАКЕТОВ
----------------------------------------------------------------
Команды выполняются от пользователя root или через sudo.

   apt update
   apt install -y python3 python3-venv python3-pip git

Проверка:

   python3 --version

   Ожидаемый вывод:  Python 3.11.x или новее (рекомендуем 3.12)


2. КОПИРОВАНИЕ ПРОЕКТА
----------------------------------------------------------------
Если проект ещё не на сервере — скопируйте папку проекта или
клонируйте репозиторий:

   git clone <адрес_репозитория> bot-grades
   cd bot-grades


3. СОЗДАНИЕ ВИРТУАЛЬНОГО ОКРУЖЕНИЯ И УСТАНОВКА ЗАВИСИМОСТЕЙ
----------------------------------------------------------------
Рекомендуем ставить зависимости в виртуальное окружение:

   python3 -m venv .venv
   source .venv/bin/activate
   python -m pip install --upgrade pip
   python -m pip install -r requirements.txt

Либо вручную (внутри окружения):

   python -m pip install netschoolapi maxapi pytest pytest-asyncio

Проверка (опционально): запуск тестов

   python -m pytest

Ожидаемый вывод:  4 passed


4. СОЗДАНИЕ ФАЙЛА КОНФИГУРАЦИИ config.json
----------------------------------------------------------------
Скопируйте шаблон и заполните реальными данными:

   cp config.example.json config.json

Отредактируйте config.json (например, через nano):

   nano config.json

Поля:
   - ns_login      — логин учётной записи «Сетевой город»
   - ns_password   — пароль от «Сетевого города»
   - ns_school     — название школы, например "МОУ \"Лицей № 4\""
   - max_bot_token — токен бота MAX (см. инструкцию REGISTER_MAX_BOT.txt)

Пример:

   {
     "ns_login": "Ученик123",
     "ns_password": "Пароль123",
     "ns_school": "МОУ \"Лицей № 4\"",
     "max_bot_token": "AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw"
   }

ВАЖНО: файл config.json не попадает в git (он в .gitignore).
Не делитесь им. Убедитесь, что права на файл закрыты:

   chmod 600 config.json


5. ПРОВЕРКА ДОСТУПА К ДНЕВНИКУ (ОПЦИОНАЛЬНО)
----------------------------------------------------------------
Убедитесь, что логин/пароль/школа верны:

   python main.py


6. ЗАПУСК БОТА
----------------------------------------------------------------
Обычный запуск (в активном виртуальном окружении):

   python bot.py

В логах ищите строку:  INFO ...: Polling started

Остановка: Ctrl+C


7. АВТОМАТИЧЕСКИЙ ЗАПУСК ЧЕРЕЗ systemd (РЕКОМЕНДУЕТСЯ)
----------------------------------------------------------------
Чтобы бот запускался при старте системы и перезапускался
при сбоях, создайте unit-файл systemd.

Создайте файл /etc/systemd/system/grades-bot.service:

   [Unit]
   Description=MAX bot for school grades
   After=network-online.target
   Wants=network-online.target

   [Service]
   Type=simple
   User=<имя_пользователя>
   WorkingDirectory=/путь/до/проекта/bot-grades
   ExecStart=/путь/до/проекта/bot-grades/.venv/bin/python bot.py
   Restart=always
   RestartSec=10
   Environment=LANG=ru_RU.UTF-8

   [Install]
   WantedBy=multi-user.target

Замените:
   - <имя_пользователя>         — пользователя, от которого работает бот
   - /путь/до/проекта/bot-grades — полный путь к папке проекта

Пример для пользователя grader и пути /opt/bot-grades:

   ExecStart=/opt/bot-grades/.venv/bin/python bot.py

Включите и запустите сервис:

   systemctl daemon-reload
   systemctl enable --now grades-bot

Проверка статуса:

   systemctl status grades-bot

Логи сервиса:

   journalctl -u grades-bot -f


8. ПРОВЕРКА РАБОТЫ БОТА В MAX
----------------------------------------------------------------
1. Откройте мессенджер MAX.
2. Найдите бота по никнейму (например, @idИНН_bot) или по ссылке
   max.ru/idИНН_bot.
3. Отправьте /start (или нажмите «Начать»).
4. В ответ придёт приветствие и кнопка «Получить оценки».
5. Нажмите кнопку — бот пришлёт оценки за последние 7 дней.
6. Команды:
     /оценки         — оценки за последние 7 дней
     /оценки месяц   — оценки за последние 30 дней

Бот отвечает ТОЛЬКО в личных чатах.


9. ЧАСТЫЕ ПРОБЛЕМЫ
----------------------------------------------------------------
- Ошибка InvalidToken сразу при запуске bot.py
    → пустой max_bot_token в config.json. Вставьте реальный токен.
- Ошибка авторизации «Сетевой город» (Ошибка при получении оценок)
    → неверные ns_login / ns_password / ns_school в config.json.
- Бот запущен от другого пользователя и не читает config.json
    → проверьте права: файл должен принадлежать пользователю из
      [Service]-секции и иметь права 600/644.
- Недоступен pip / нет интернета для установки
    → обновите apt: apt update, затем повторите шаг 1.
- В systemd логах ошибка кодировки
    → добавьте Environment=LANG=ru_RU.UTF-8 в секцию [Service]
      (уже указано в шаблоне выше).
