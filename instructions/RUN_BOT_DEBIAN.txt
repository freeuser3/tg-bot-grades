ИНСТРУКЦИЯ: ЗАПУСК БОТА ОЦЕНОК НА DEBIAN
===============================================================

Состав проекта:
  config.example.json     — шаблон конфигурации
  config.json             — реальная конфигурация (создаётся, в git не хранится)
  grades.py               — загрузка конфига, запрос и форматирование оценок
  main.py                 — CLI: печать оценок в консоль (для проверки)
  bot.py                  — сам бот (Telegram, aiogram)
  requirements.txt        — зависимости
  tests/                  — тесты
  instructions/           — инструкции (REGISTER_TG_BOT.txt и др.)


1. УСТАНОВКА PYTHON И ПАКЕТОВ
---------------------------------------------------------------
Команды выполняются от пользователя root или через sudo.

   apt update
   apt install -y python3 python3-venv python3-pip git

Проверка:

   python3 --version

   Ожидаемый вывод:  Python 3.11.x или новее (рекомендуем 3.12)


2. КОПИРОВАНИЕ ПРОЕКТА
---------------------------------------------------------------
Если проект ещё не на сервере — скопируйте папку проекта или
клонируйте репозиторий:

   git clone <адрес_репозитория> bot-grades
   cd bot-grades


3. СОЗДАНИЕ ВИРТУАЛЬНОГО ОКРУЖЕНИЯ И УСТАНОВКА ЗАВИСИМОСТЕЙ
---------------------------------------------------------------
Рекомендуем ставить зависимости в виртуальное окружение:

   python3 -m venv .venv
   source .venv/bin/activate
   python -m pip install --upgrade pip

ВАЖНО: пакеты ставим точными версиями и В ЭТОМ ПОРЯДКЕ.
Порядок критичен: иначе pip из-за зависимости netschoolapi
(typing-extensions==4.4.0) откатит aiogram до старой 2.x
или поставит несовместимый pydantic.

   python -m pip install netschoolapi==11.0.5
   python -m pip install aiogram==3.7.0 pydantic==2.6.4 pydantic_core==2.16.3 typing-extensions==4.16.0
   python -m pip install aiohttp-socks Pillow pytest pytest-asyncio

Предупреждение pip "netschoolapi requires typing-extensions==4.4.0,
but you have ..." — НЕ ГЛЭТ: версия 4.16.0 совместима и проверена.

Проверка импорта (должно занять 2-10 секунд, НЕ прерывайте Ctrl+C):

   python -c "import aiogram; print(aiogram.__version__)"

Ожидание:  3.7.0

Тесты (опционально):

   python -m pytest

Ожидаемый вывод:  13 passed


4. СОЗДАНИЕ ФАЙЛА КОНФИГУРАЦИИ config.json
---------------------------------------------------------------
Скопируйте шаблон и заполните реальными данными:

   cp config.example.json config.json

Отредактируйте config.json (например, через nano):

   nano config.json

Поля:
   - ns_login      — логин учётной записи «Сетевой город»
   - ns_password   — пароль от «Сетевого города»
   - ns_school     — название школы, например "МОУ \"Лицей № 4\""
   - tg_bot_token  — токен бота Telegram (см. инструкцию
                      instructions/REGISTER_TG_BOT.txt)
   - use_proxy     — true/false: ходить к Telegram через прокси
   - proxy_url     — адрес прокси (обязателен, если use_proxy=true),
                     например "socks5://127.0.0.1:10808"
   - output_mode   — "image" — оценки картинкой (PNG),
                     "text" — оценки текстом (запасной вариант).

Примечание: шрифт для картинок (Noto Sans) лежит в папке fonts/
проекта — отдельная установка шрифтов на Debian не нужна.

Пример:

   {
     "ns_login": "Ученик123",
     "ns_password": "Пароль123",
     "ns_school": "МОУ \"Лицей № 4\"",
     "tg_bot_token": "1234567890:AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw",
     "use_proxy": false,
     "proxy_url": "socks5://127.0.0.1:10808"
   }

ВАЖНО: файл config.json не попадает в git (он в .gitignore).
Не делитесь им. Убедитесь, что права на файл закрыты:

   chmod 600 config.json


5. ПРОВЕРКА ДОСТУПА К ДНЕВНИКУ (ОПЦИОНАЛЬНО)
---------------------------------------------------------------
Убедитесь, что логин/пароль/школа верны:

   python main.py


6. ЗАПУСК БОТА
---------------------------------------------------------------
Обычный запуск (в активном виртуальном окружении):

   python bot.py

В логах ищите строку:  INFO ...: Start polling

Остановка: Ctrl+C


7. АВТОМАТИЧЕСКИЙ ЗАПУСК ЧЕРЕЗ systemd (РЕКОМЕНДУЕТСЯ)
---------------------------------------------------------------
Чтобы бот запускался при старте системы и перезапускался
при сбоях, создайте unit-файл systemd.

Создайте файл /etc/systemd/system/grades-bot.service:

   [Unit]
   Description=Telegram bot for school grades
   After=network-online.target
   Wants=network-online.target

   [Service]
   Type=simple
   User=<имя_пользователя>
   WorkingDirectory=/путь/до/проекта/bot-grades
   ExecStart=/путь/до/проекта/bot-grades/.venv/bin/python bot.py
   Restart=always
   RestartSec=10
   Environment=LANG=ru_RU.UTF-8

   [Install]
   WantedBy=multi-user.target

Замените:
   - <имя_пользователя>         — пользователя, от которого работает бот
   - /путь/до/проекта/bot-grades — полный путь к папке проекта

Пример для пользователя grader и пути /opt/bot-grades:

   ExecStart=/opt/bot-grades/.venv/bin/python bot.py

Включите и запустите сервис:

   systemctl daemon-reload
   systemctl enable --now grades-bot

Проверка статуса:

   systemctl status grades-bot

Логи сервиса:

   journalctl -u grades-bot -f


8. ПРОВЕРКА РАБОТЫ БОТА В TELEGRAM
---------------------------------------------------------------
1. Откройте Telegram.
2. Найдите бота по username (например, @my_school_grades_bot)
   или по ссылке t.me/my_school_grades_bot.
3. Отправьте /start (или нажмите «Начать»).
4. Бот пришлёт приветствие, а над строкой ввода появится
   постоянная кнопка «📊 Получить оценки».
5. Нажмите её — бот пришлёт оценки. Если output_mode="image"
   — придёт картинка-таблица (PNG), если "text" — текст
   с эмодзи-оценками (5️⃣, 4️⃣, ...).
6. Команды:
     /оценки         — оценки за последние 7 дней
     /оценки месяц   — оценки за последние 30 дней

Бот отвечает ТОЛЬКО в личных чатах.


9. ЧАСТЫЕ ПРОБЛЕМЫ
---------------------------------------------------------------
- «В config.json не задан tg_bot_token»
    → Вставьте реальный токен от @BotFather (см.
      instructions/REGISTER_TG_BOT.txt).
- Соединение с Telegram недоступно, но прокси настроен
    → проверьте use_proxy=true и proxy_url (например,
      "socks5://127.0.0.1:10808"). Прокси-сервер должен быть запущен.
- Ошибка авторизации «Сетевой город» (Ошибка при получении оценок)
    → неверные ns_login / ns_password / ns_school в config.json.
- Бот запущен от другого пользователя и не читает config.json
    → проверьте права: файл должен принадлежать пользователю из
      [Service]-секции и иметь права 600/644.
- Недоступен pip / нет интернета для установки
    → обновите apt: apt update, затем повторите шаг 1.
- В systemd логах ошибка кодировки
    → добавьте Environment=LANG=ru_RU.UTF-8 в секцию [Service]
      (уже указано в шаблоне выше).
- Бот долго стартует / висит при импорте (мало ОЗУ)
    → импорт aiogram генерирует схемы ~200 моделей и на слабом
      VPS (512 МБ ОЗУ) может занять 1-5 минут. НЕ прерывайте
      Ctrl+C сразу — дайте отработать. Если импорт реально не
      завершается — добавьте swap:
        sudo fallocate -l 1G /swapfile
        sudo chmod 600 /swapfile
        sudo mkswap /swapfile
        sudo swapon /swapfile
      (для постоянного монтирования добавьте строку
       "/swapfile none swap sw 0 0" в /etc/fstab).
- aiogram 2.x: ошибка "cannot import name 'F' from 'aiogram'"
    → неверный порядок установки. Переустановите строго по
      порядку из раздела 3 (aiogram==3.7.0 после netschoolapi).
