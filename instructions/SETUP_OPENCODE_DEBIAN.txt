SETUP_OPENCODE_DEBIAN.txt
=======================
Как запустить opencode (AI-агент) на Debian-сервере
и передать ему контекст проекта бота оценок.


1. УСТАНОВКА OPENCODE
---------------------
curl -fsSL https://opencode.ai/install | bash

Если curl не установлен:
   apt update && apt install -y curl

После установки бинарник обычно в ~/.opencode/bin или /usr/local/bin.
Проверка: opencode --version

Прочие способы (если вдруг нужен npm):
   npm install -g opencode-ai

ВАЖНО: после установки закрыть и открыть терминал (или выполнить
`source ~/.bashrc`), чтобы PATH подхватился.


2. API-КЛЮЧ ДЛЯ МОДЕЛИ
----------------------
Открой opencode, в TUI набери /connect, выбери провайдера/модель,
вставь API-ключ. Либо задай через переменные окружения
(для большинства провайдеров это ANTHROPIC_API_KEY / OPENAI_API_KEY
или аналогичные — смотри opencode.ai/docs). Ключ можно хранить
в ~/.bashrc или в конфиге opencode.


3. ЗАПУСК НА ПРОЕКТЕ БОТА
-------------------------
cd ~/pyt/grades_bot
opencode

После запуска впервый раз можно выполнить /init, чтобы сгенерировать
AGENTS.md (описание проекта) — рекомендуется закоммитить.
Потом просто работай текстом в TUI (как с ChatGPT).


4. ПЕРЕДАЧА КОНТЕКСТА ПРЕДЫДУЩЕЙ РАБОТЫ
---------------------------------------
В корне проекта лежит файл DEBIAN_HANDOFF.md — полный слепок состояния
проекта, активной проблемы (зависание импорта aiogram) и плана действий.

Чтобы агент увидел его содержимое, упомяни файл в первом сообщении:
   "Прочитай DEBIAN_HANDOFF.md и продолжи работу с того места, где остановились."

Либо добавь инструкцию о нём в AGENTS.md, чтобы агент читал
DEBIAN_HANDOFF.md автоматически при старте каждой сессии.


5. СОВЕТЫ ПО РЕСУРСАМ VPS
-------------------------
- Импорт aiogram на слабом сервере может занимать несколько минут —
  НЕ прерывай Ctrl+C сразу, дай боту спокойно стартовать (см. DEBIAN_HANDOFF.md).
- Для запуска агента на сервере с 1 CPU работай в screen/tmux, чтобы
  сессия не прервалась при отключении от SSH:
    apt install -y screen tmux
    screen -S work
    opencode

6. ЧЕГО ИЗБЕГАТЬ
----------------
- Не использовать AI-агента для изменения config.json (секреты) и не
  коммитить его в git.
- Не удалять fonts/ и renderer.py — это часть продукта.
- Не «чинить» зависание импорта установкой aiogram без точных версий —
  см. DEBIAN_HANDOFF.md, раздел 5.
