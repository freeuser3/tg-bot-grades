# Дизайн: бот в Telegram для просмотра школьных оценок

Дата: 2026-09-15 | обновлено: 2026-09-16 (перенос MAX → Telegram, бета: картинки)

## Цель

Бот в Telegram, который показывает оценки ученика из электронного дневника «Сетевой город» (netschoolapi).

> Верификация бизнеса для MAX (юрлица/ИП/самозанятые, резиденты РФ) была непреодолимым
> ограничением. Telegram выдаёт токен мгновенно через @BotFather без ограничений.

## Компоненты

- **`main.py`** — CLI: выводит оценки в консоль (для проверки доступа к дневнику).
- **`grades.py`** — логика дневника: `load_config()`, `format_diary()`, `async fetch_diary(start, end) -> Diary`, `async get_grades(start, end)`.
- **`renderer.py`** — генерация PNG-картинки журнала через Pillow
  (`render_diary_image(diary, font_dir=...) -> bytes`, дизайн «светлые карточки»,
  720px ширина, авто-высота, оценки — цветные кружки).
  Шрифты — бандл `fonts/NotoSans-{Regular,Bold,Italic}.ttf` (кириллица,
  работает на Windows и Debian без установки дополнительных пакетов).
- **`bot.py`** — чат-бот на **aiogram 3.31** (async-native, совместим с asyncio `get_grades`).
  Команды:
  - `/start` — приветствие + постоянная reply-клавиатура «📊 Получить оценки»
  - `/оценки` — оценки за текущую неделю
  - `/оценки месяц` — оценки за последние 30 дней
  - Кнопка «📊 Получить оценки» под строкой ввода — оценки за 7 дней
    (обрабатывается как текст, не inline-callback)
- **Конфигурация** — файл `config.json`:
  - `ns_login`, `ns_password`, `ns_school` — учётные данные дневника
  - `tg_bot_token` — токен бота Telegram (получен через @BotFather)
  - `use_proxy` (bool) / `proxy_url` (str) — включать ли подключение к
    Telegram через SOCKS-прокси (например, `socks5://127.0.0.1:10808`).
    Если `use_proxy=false` — бот подключается напрямую.
  - `output_mode` — `"image"` (по умолчанию, PNG-картинка) или `"text"`
    (текст с эмодзи-оценками — запасной вариант).
  - Пример: `config.example.json` в репозитории; реальный `config.json` в `.gitignore`.

## Поток данных

1. Пользователь отправляет `/start` боту в **личном чате** Telegram.
2. Бот отвечает приветствием и отправляет reply-клавиатуру
   с кнопкой «📊 Получить оценки» (появляется над строкой ввода).
3. Пользователь нажимает кнопку (или команду `/оценки`).
4. Бот вызывает `fetch_diary(start, end)`, получает `Diary`.
5. Если `output_mode == "image"` — `render_diary_image(diary)` даёт PNG,
   бот отправляет `answer_photo`. Если `"text"` — `format_diary()` даёт текст,
   бот отправляет `answer`.
6. `netschoolapi` делает запрос в дневник, возвращает расписание с оценками.

## Формат вывода

### Картинка (по умолчанию, `output_mode="image"`)

- Портретная PNG-таблица: ширина 720px, высота авто по контенту.
- Дни — вертикальные скруглённые карточки на светлом фоне.
- Оценки — цветные кружки (5 зелёный → 1 красный), предметы слева.
- День без оценок: «Оценок нет» внутри карточки.
- Шрифт Noto Sans (бандл в `fonts/`).

### Текст (запасной, `output_mode="text"`)

- Дни сортируются по дате: `--- 2026-09-16 ---`.
- Показываются только предметы с оценками: `  Физика: 5️⃣, 4️⃣`.
- Оценки — эмодзи-цифры (1️⃣–5️⃣); нестандартное значение выводится как число.
- День без оценок: `  —`.

## Команда «месяц» и аргументы

aiogram 3 парсит аргументы команды в `CommandObject.args`:
`/оценки месяц` → command="оценки", args="месяц".
Это решает проблему, из-за которой в maxapi команда «оценки месяц»
никогда не срабатывала (Command берёт только первый токен).

## Обработка ошибок

- Неверные учётные данные дневника → бот отвечает понятным сообщением.
- Ошибка сети → ответ-ошибка (netschoolapi ловит исключения).
- Бот отвечает ТОЛЬКО в личных чатах (`F.chat.type == "private"` в декораторах:
  `/start`, `/оценки`, кнопка).

## Запуск

Polling (`dp.start_polling(bot)`) для локальной разработки.
Webhook — позже при необходимости (production).

При `use_proxy=true` бот создаёт `AiohttpSession(proxy=proxy_url)` (aiohttp-socks)
и передаёт её в `Bot`. Это необходимо в сетях, где api.telegram.org заблокирован.

## Установка зависимостей

```
pip install aiogram aiohttp-socks Pillow
```
