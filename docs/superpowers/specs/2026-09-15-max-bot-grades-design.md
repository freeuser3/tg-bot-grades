# Дизайн: бот в мессенджере MAX для просмотра школьных оценок

Дата: 2026-09-15

## Цель

Бот в мессенджере MAX, который показывает оценки ученика из электронного дневника «Сетевой город» (netschoolapi).

## Компоненты

- **`main.py`** (существующий) — логика получения оценок через `netschoolapi`.
  Рефакторинг: выделить функцию `get_grades(start, end) -> str` которая возвращает
  отформатированный текст дневника за период.
- **`bot.py`** (новый) — чат-бот на `maxapi` (официально одобренная командой MAX библиотека).
  Команды:
  - `/оценки` — оценки за текущую неделю
  - `/оценки месяц` — оценки за последние 30 дней
- **Конфигурация** — через переменные окружения:
  - `NS_LOGIN`, `NS_PASSWORD`, `NS_SCHOOL` — учётные данные дневника
  - `MAX_BOT_TOKEN` — токен бота MAX

## Поток данных

1. Пользователь отправляет команду боту в MAX.
2. Бот вызывает `get_grades(start, end)`.
3. `netschoolapi` делает запрос в дневник, возвращает расписание с оценками.
4. Бот отправляет отформатированный текст обратно в чат.

## Обработка ошибок

- Неверные учётные данные дневника → бот отвечает понятным сообщением.
- Ошибка сети → повторная попытка, иначе сообщение об ошибке.
- Бот отвечает только в личных чатах (защита от посторонних).

## Запуск

Polling (`dp.start_polling(bot)`) для локальной разработки.
Webhook — позже при необходимости (production).
